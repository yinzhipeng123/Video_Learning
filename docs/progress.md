# 本机学习状态

学习状态存放在 APP 私有的 Preferences DataStore 中，以稳定 `videoId` 为键。目录排序、课程序号和 token 变化不会改变真实视频 ID；多个章节共用同一视频时共享学习状态。

- 打开课程只更新最近打开时间，保留已有播放位置和完成标记。
- 手动标记或取消“已学完”只修改完成状态，不改动播放位置、最近打开时间或其他视频状态。
- 播放器返回有效的非负毫秒位置时才保存；null 或负值表示未获得位置，保留之前的有效位置。明确拖动到 0 是有效位置。
- 没有进度回调时仍保存打开状态和手动完成标记，不凭页面加载完成判断学生学完。
- DataStore 没有内容或 JSON 不可解析时，返回空学习状态；课程目录本身仍从 APK 内置资源加载。

## 自动验证

运行 `gradlew.bat :app:testDebugUnitTest`。`LearningProgressRepositoryTest` 使用临时文件上的真实 Preferences DataStore 和可控制时钟；测试关闭首个 DataStore 后再创建第二个实例，验证实际落盘后的序列化恢复，而非仅检查内存缓存。

覆盖打开课程后保留位置、完成标记取消、隔离其他视频、缺失位置回调、列表重排、共用视频、重新实例化、清空存储和坏 JSON。JSON JVM 测试依赖 `org.json`，不需要 Android 模拟器。

## 设备验收：清除应用数据

1. 安装 APK，打开任意课程，播放一段视频并退出；在详情页手动标记“已学完”。确认列表与详情显示已完成。
2. 强行停止 APP 后重新打开。确认已完成标记仍在；播放器能提供位置时，检查“继续学习”恢复到保存位置。
3. 在 Android 设置中找到“应用 → 文旅学堂 → 存储 → 清除数据”（应用名以实际安装名为准），或者在连接的专用验收设备运行 `adb shell pm clear com.yzp.videolearning`。这一步会删除该 APP 的本机学习记录。
4. 重新打开 APP，确认三类课程目录可以加载、之前的完成标记和最近打开状态已清除；关掉网络仍能浏览目录，播放时提示需要网络。
5. 再次打开并完成一门课程，确认新的学习记录可保存。

“清空 Preferences”的自动测试验证仓库行为，不能代替上面的设备级清除数据和实际播放器验收。尚未完成设备验收时，应明确记录为待验证。

2026-11-25 已在项目 Android 15 模拟器上执行上述强制停止、重启、取消完成、关闭网络和 `pm clear` 检查，均通过。具体结果和设备范围见 [首版验收记录](acceptance.md)。
